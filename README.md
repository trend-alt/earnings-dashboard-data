# Earnings DashBoard data

A daily job (07:41 IST) collects the expected result dates and the last 8 quarters of revenue and profit for Nifty 500 companies. It publishes `app-data.json` for the Earnings DashBoard Android app.

- Sources: NSE index lists (Nifty 500 constituents), Yahoo Finance (via yfinance) and Screener.in.
- Data only. Not investment advice. Figures may be delayed or wrong.
- Privacy policy: [privacy.html](privacy.html)
